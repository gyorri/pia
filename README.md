# PIA v0.3.4 — CSV 일괄 등록 작업실

기준: 사용자가 업로드한 `pia-main.zip` + v0.3.3 공개 화면 패치.

## 적용
GitHub 저장소에 ZIP 내부 파일을 같은 경로로 덮어쓰기: `public/import.html`, `public/import.js`, `public/admin.html`, `README.md`, `HISTORY.md`. 기존 데이터와 D1 스키마 변경 없음.

관리자 로그인 후 `/import.html` 접속. **엑셀(.xlsx) 파일은 직접 읽지 않음**. `게시물` 시트를 UTF-8 CSV로 내보내 업로드. 제공받은 `PIA_X_게시물.csv` 사용 가능.

## 작동
- 업로드 후 미리보기, 날짜 누락·원본 확인 필요·중복 의심 표시
- 기본적으로 검토 통과한 행만 선택
- 기존 DB의 @아이디를 대소문자 구분 없이 찾아 재사용, 없는 계정만 생성
- 원글 먼저 저장, 같은 CSV에서 선택한 답글을 `temp_id` 기준 연결
- 같은 작성자·본문·작성 시각이 이미 DB에 있으면 저장하지 않고 기존 ID를 재사용해 답글 연결
- 선택 항목 순차 저장. 오류 발생 시 앞서 저장된 건은 롤백되지 않음

## 주의
- 원본 날짜·시간이 없는 행은 등록 불가. 날짜를 임의로 채우지 않음.
- 작성 시각의 시간대는 업로드 화면에서 선택(기본 +09:00). 원본이 다른 시간대면 변환 전에 검토.
- 검토 필요 항목은 원본과 대조한 후 수동 선택할 수 있음.
- 파일에 없는 부모 게시물은 연결 불가. 미선택 부모를 가진 답글은 저장되지 않음.
- 이 기능은 브라우저에서 CSV를 분석하고 기존 관리자 API로 **순차 등록**함. 별도 대량 등록 API나 DB 마이그레이션 없음.
- CSV 안의 원본 실명·아이디·본문은 관리자에게 표시됨. 공개 익명화 시에도 본문 실명은 자동 변경되지 않음.
