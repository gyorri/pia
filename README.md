# PIA v0.3.21 — X 액션 바 정렬/위치 보정

기준: v0.3.20 공개 화면 보정본 위에서 추가 수정했습니다.

## 이번 핵심 수정
- 게시물 하단 액션 바를 X에 더 가깝게 왼쪽 4개 반응 + 오른쪽 2개 유틸리티 구조로 재정렬
- 답글/좋아요/조회수 숫자가 아이콘 오른쪽에 자연스럽게 붙도록 정렬 수정
- 북마크/공유 아이콘이 우측 끝에 과도하게 벌어지지 않도록 위치 보정
- 답글 말풍선, 조회수 아이콘 SVG를 더 X에 가까운 형태로 미세 조정
- 모바일(400px/320px)에서도 숫자와 아이콘 위치가 틀어지지 않도록 보정

## 변경 파일
- `public/app.js`
- `public/style.css`
- `README.md`
- `HISTORY.md`

## 적용 방법
1. ZIP 압축 해제
2. GitHub 저장소 루트에 같은 경로로 덮어쓰기
3. 커밋 후 Cloudflare Pages 배포
4. 타임라인/상세/모바일에서 하단 액션 바 정렬 확인

## 주의
- DB 마이그레이션은 필요 없습니다.
- 이번 패치는 특히 하단 액션 바의 정렬·간격·숫자 위치 보정에 집중했습니다.

## 테스트
- `node --check public/app.js`
- 패치 ZIP 무결성 확인
