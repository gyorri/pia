# PIA v0.2.8 익명화 통합 패치

이 ZIP은 **v0.2.4가 적용된 사이트**에 v0.2.5~v0.2.7 홈/날짜/모바일 변경과 익명화 기능을 함께 적용하는 패치입니다. 원래 폴더 경로를 유지해 업로드하세요.

1. Cloudflare D1 콘솔에서 `migration-v0.2.8.sql` 실행 (여러 번 실행 가능).
2. ZIP의 `public/`, `functions/` 경로를 GitHub에 덮어쓰기.
3. Pages 배포 후 관리자 로그인 → **공개 화면 익명화** 체크.
4. 원본은 관리자에서 계속 확인 가능하며 공개 `/api/data` 응답에서는 계정 닉네임·핸들·소개·프로필 이미지가 가려집니다.

주의: **게시물 본문, 인용 본문, 외부 URL, 이미지에 포함된 개인 정보는 자동으로 익명화되지 않습니다.** 인용 카드 작성자 표시는 일괄 가명 처리합니다. DB의 실제 값은 보존됩니다. 익명화된 화면을 공개하려면 반드시 본문도 검토하세요. 관리자 API는 세션 인증이 필요합니다.

익명화 별칭은 계정 생성 순서에 따라 유저 A, 유저 B 순으로 부여됩니다. 계정 삭제/추가 시 순서가 달라질 수 있습니다. 실제 배포 환경에서 아직 통합 검증하지 않았습니다.
