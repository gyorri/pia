# PIA v0.3.2 — 빠른 등록 중복 알림

**적용 기준:** v0.3.1. `public/app.js`, `public/style.css`, `public/index.html`을 GitHub의 같은 경로에 덮어씁니다. D1 마이그레이션은 필요 없습니다.

- 빠른 게시물/답글 등록 창에서 작성자를 선택하고 내용을 8글자 이상 입력하면, 해당 작성자의 기존 게시물과 비교해 일치/유사한 글 최대 4건을 경고 영역(토스트 형태)으로 보여줍니다.
- 작성자를 변경하면 즉시 해당 작성자 기준으로 다시 검색합니다. 280ms 입력 디바운스를 적용합니다.
- 원본 날짜·시간과 기존 본문 일부, 기존 글 열기 링크를 제공합니다.
- 경고는 저장을 막지 않습니다. 입력 내용은 중복 검색을 위해 외부로 전송하지 않습니다. 이미 인증된 관리자 데이터(`/api/admin-data`)만 사용합니다.
- v0.3.1의 타임라인 빠른 답글·프로필 게시물 작성 기능은 유지합니다.
- 실제 Cloudflare 배포 환경 테스트는 별도로 필요합니다.
