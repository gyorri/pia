# PIA v0.2.3 인용 카드 패치

## 필수 적용 순서
1. Cloudflare D1 Console에서 `migration-v0.2.3.sql`의 ALTER TABLE 4개 문장을 **한 번만** 실행합니다. 기존 테이블이나 데이터는 삭제하지 않습니다. 이미 실행했다면 다시 실행하지 마세요.
2. `public/admin.html`, `public/admin.js`, `public/app.js`, `functions/api/[[path]].js`를 GitHub 저장소의 같은 경로에 덮어씁니다.
3. Cloudflare Pages 자동 배포가 성공한 후 관리자 페이지에서 인용 게시물을 등록합니다.

## 기능
- 일반 게시물/답글/인용 게시물 선택
- 인용 게시물은 원문 닉네임, @아이디, 본문, 선택적 작성 일시를 별도 필드에 저장
- 인용 원문은 별도의 계정이나 타임라인 게시물로 생성되지 않음
- 인용 카드는 타임라인과 게시물 상세에서 표시되며 계정 링크로 이동하지 않음
- 기존 게시물의 수정 및 인용 정보 삭제 지원
- 공개 타임라인의 기존 X 유사 레이아웃 유지

주의: 배포 전에 D1 마이그레이션이 필수입니다. 관리자 인증은 기존 ADMIN_PASSWORD 설정을 사용합니다. 이 버전은 인용 원문 이미지 첨부 기능을 포함하지 않습니다.
