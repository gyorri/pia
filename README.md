# PIA v0.3.12 — X 날짜 복사 붙여넣기 추가

기준: v0.3.11 통합 패치. 기존 신규·수정·관리자 날짜 붙여넣기와 체크박스 레이아웃 개선 포함.

- `오후 2:15 · 2025년 12월 30일`을 `2025-12-30T14:15`로 변환. 오전 12시는 00시, 오후 12시는 12시.
- 타임라인 신규·수정, 관리자 게시물 및 인용 날짜에 적용. 기존 숫자형 날짜도 유지.
- 잘못된 날짜는 반영하지 않으며, 저장 버튼을 눌러야 저장됩니다.
- DB/API 변경 및 마이그레이션 없음.

적용: ZIP을 GitHub 저장소 루트에 덮어쓰고 커밋·배포 후 실제 브라우저에서 테스트하세요.
