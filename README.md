# PIA v0.3.14 — X 날짜 붙여넣기 형식 추가

기존 v0.3.13 인용 게시물 연결 패치에 날짜 역순 표기 지원을 추가한 **통합 패치**입니다.

- `2023. 8. 10. · 오전 12:04` → `2023-08-10T00:04`
- `2024. 5. 3. · 오후 12:30` → `2024-05-03T12:30`
- 기존 `오후 2:15 · 2025년 12월 30일` 형식 유지
- 공개 화면 신규/빠른 등록 및 수정, 관리자 등록·수정과 인용 날짜 입력에 적용
- 잘못된 날짜는 입력하지 않고 검토 안내를 표시

## 적용
1. 운영 D1 백업.
2. **v0.3.13 마이그레이션을 아직 적용하지 않았다면** `migration-v0.3.13.sql`을 운영 D1에 1회 적용. 이미 적용했다면 반복하지 않음.
3. ZIP을 GitHub 저장소 루트에 동일 경로로 덮어쓰기 후 커밋 및 배포.
4. 실제 브라우저에서 날짜 붙여넣기와 인용 연결 기능 확인.

기존 v0.3.13 패치를 별도로 적용할 필요는 없습니다. 실제 브라우저/배포 테스트는 수행하지 않았습니다.
