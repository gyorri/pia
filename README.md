# PIA v0.3.10 — 게시물 수정 날짜 붙여넣기

기준본: 사용자가 제공한 `pia-main(1).zip` (README 표기 v0.3.9).

## 변경
- 타임라인 게시물 **수정** 팝업의 `원본 날짜·시간 (한국 시간)` 필드에서 날짜 문자열을 붙여넣으면 `datetime-local` 값으로 변환합니다.
- 지원 예: `2026-10-15 14:30`, `2026-10-15 14:30:00`, `2026-10-15T14:30`, `2026. 10. 15. 오후 2:30`.
- 실제 존재하지 않는 날짜 또는 형식이 맞지 않는 문자열은 반영하지 않고 안내합니다.
- 붙여넣기는 저장이 아닙니다. **변경 저장** 버튼을 눌러야 DB에 반영됩니다.
- 기존 수정 날짜, 답글 등록 기본값, CSV 가져오기, DB/API는 변경하지 않습니다.

## 적용
ZIP을 풀어 저장소 루트에 `public/app.js`, `README.md`, `HISTORY.md`를 같은 경로로 덮어쓰고 GitHub에 커밋한 뒤 Cloudflare Pages 배포를 확인하세요. 브라우저 새로고침 후 수정 팝업에서 테스트하세요. D1 마이그레이션은 필요 없습니다.

# PIA v0.3.9 — 수동 답글 날짜 기본값

기준: v0.3.8 적용 상태. `public/app.js`만 덮어쓰기.

- 타임라인에서 답글을 빠르게 등록할 때 부모 게시물의 **한국 시간 기준 날짜**를 입력창 기본값으로 사용합니다.
- 시간은 12:00으로 설정하며, 작성자가 날짜·시간을 자유롭게 수정할 수 있습니다.
- 부모 날짜가 없거나 유효하지 않으면 기존처럼 현재 한국 시각을 기본값으로 사용합니다.
- 일반 게시물 빠른 등록은 기존처럼 현재 한국 시각이 기본값입니다.
- **기본값만 변경**하며 이미 저장된 게시물, CSV 일괄 등록, DB/API, 날짜수정필요 상태는 건드리지 않습니다.
- 임시 시각은 실제 작성 시각이 아니므로 확인 후 수정하세요.

적용 후 브라우저 새로고침을 해주세요. D1 마이그레이션은 필요 없습니다.
