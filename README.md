# PIA v0.3.1 빠른 등록 패치

기준: v0.3.0 패치가 적용된 소스. `public/`의 세 파일만 같은 경로에 덮어쓰세요. D1 마이그레이션 불필요.

- 타임라인의 말풍선 아이콘을 누르면 해당 글에 답글 작성 모달이 열립니다.
- 프로필의 `이 계정으로 게시물 작성`을 누르면 작성자가 자동 선택됩니다.
- 좌측 `게시하기` 버튼도 빠른 등록 모달을 엽니다.
- 작성 계정 선택, 본문, 원본 날짜·시간 입력 후 저장하면 화면이 새로고침됩니다.
- 관리자 로그인이 필요하며 로그인하지 않았으면 관리자 페이지로 이동할 수 있습니다.
- 익명화된 공개 화면에서 실명 계정 목록을 노출하지 않도록 인증된 `/api/admin-data`만 사용합니다.
- 기존 관리자·API·DB는 수정하지 않습니다.
