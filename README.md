# PIA v0.3.0 UX 패치

기준: 사용자가 업로드한 pia-main.zip (2026-10-20).

## 적용
ZIP 내 public/ 폴더의 6개 파일을 GitHub 저장소의 같은 경로에 덮어쓰고 커밋하세요. D1 마이그레이션은 필요 없습니다. 기존 functions/api, schema.sql, migration 파일은 변경하지 않습니다.

## 변경
- 관리자 게시물 목록에서 바로 답글 작성 버튼 추가
- 작성자 빠른 검색 및 연속 저장 시 작성자·원본 날짜·시간대 유지
- 공개 홈 탭 시각 구성, 게시물 액션/간격 개선
- 게시물 상세에서 부모 글과 답글의 연결선 및 구분 개선

## 주의
- 홈의 추천/팔로잉은 시각적 표시만 제공하며 별도 추천 알고리즘은 없습니다.
- 관리자 답글 작성 시 작성자를 원문 작성자로 임시 선택하므로 저장 전에 답글 작성자를 확인하세요.
- X의 실제 게시물/좋아요/조회 데이터와 연동하지 않습니다.
- 브라우저·Cloudflare 실제 배포 환경 테스트는 별도로 필요합니다.
