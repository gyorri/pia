# PIA v0.2.9 — X 레이아웃 정밀화 패치

## 기준
GitHub 공개 저장소 `gyorri/pia`의 v0.2.8 화면 CSS를 기준으로 작업했습니다.

## 적용
`public/style.css` 파일만 동일 경로로 교체합니다. 기존 관리자 화면, API, D1, 익명화, 날짜 정렬, 계정 이동은 수정하지 않습니다.

브라우저에서 기존 CSS가 캐시된 경우 강력 새로고침하세요. 기존 HTML의 `/style.css?v=7` 참조는 유지되므로 Cloudflare 또는 브라우저 캐시가 남으면 캐시 제거가 필요할 수 있습니다.

## 주요 변경
- 라이트 모드의 왼쪽 메뉴, 검색창, hover 색상 정리
- 데스크톱 3열 배치와 중앙 타임라인 최대 너비 정리
- 게시물 헤더, 본문, 액션 아이콘 간격 조정
- 프로필 배너/아바타 및 탭 표시 개선
- 모바일 4개 하단 메뉴와 게시물 너비 보정
- 인용 카드 테두리 및 우측 계정 패널 개선

## 검증 범위
CSS 정적 구문과 ZIP 구조만 점검했습니다. 실제 X와 픽셀 단위 일치, Cloudflare 배포 및 실기기 렌더링은 검증되지 않았습니다.
