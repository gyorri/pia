# PIA v0.3.8 모바일 헤더 및 타임라인 관리 패치

기준: v0.3.6 app.js / style.css. v0.3.7은 import.js만 변경하므로 별도로 유지됩니다.

- 모바일 상단 뒤로가기 텍스트를 SVG 아이콘으로 변경, NaN 텍스트 표시 방지
- 관리자 세션일 때 게시물 ··· 버튼 표시, 수정/삭제 팝업 제공
- 작성자, 본문, 날짜, 답글 부모, 날짜수정필요 수정 가능
- 인용 원문은 기존 값 유지
- 서버의 기존 /api/posts POST/DELETE를 사용하며 DB 마이그레이션 없음

public 폴더 3개 파일만 기존 경로에 덮어쓰기. 관리자 로그인 쿠키는 /api 경로로 설정되어 있으므로 /api/session 확인을 통해 권한 판단합니다. 서버 저장 시 별도 권한 검증이 수행됩니다.

주의: 부모 글에 연결된 답글이 있을 때 삭제는 DB 외래키 제약으로 실패할 수 있습니다. 원본 데이터 백업 권장. 실제 브라우저/D1 통합 테스트 미실시.
