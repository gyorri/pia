# PIA v0.3.25 — X 모바일 상세 레이아웃 추가 보정

기준: v0.3.24 상세 화면 보정본 위에서 추가 수정했습니다.

## 이번 핵심 수정
- 모바일 게시물 상세 화면의 하단 액션 바를 실제 X처럼 5개 컬럼으로 더 타이트하게 재배치
- 답글·리포스트·좋아요·북마크의 숫자 정렬과 baseline 보정
- 북마크 수(`bookmark_count`)가 데이터에 존재하는 경우 상세 화면에 숫자 표시 지원
- 날짜·조회수 줄의 간격, 굵기, 강조 비율 조정
- 상세 화면 아래 이어지는 게시물 카드의 세로 간격을 더 조밀하게 보정

## 변경 파일
- `public/app.js`
- `public/style.css`
- `README.md`
- `HISTORY.md`

## 주의
- 북마크 숫자는 데이터에 `bookmark_count`가 있을 때만 표시됩니다. 없으면 아이콘만 표시됩니다.
- DB 마이그레이션은 필요 없습니다.
