# PIA v0.3.7 부모 게시물 연결 보정

기존 v0.3.6이 적용된 상태에서 `public/import.js`만 교체합니다.

- 선택하지 않은 부모 게시물도 같은 CSV에 있으면 자동 포함해 저장을 시도합니다.
- 부모 게시물이 기존 DB에 이미 있으면 작성자 @아이디와 본문으로 찾아 연결합니다.
- 본문이 동일한 게시물이 여러 개이고 원본 날짜가 미상인 경우 자동 매칭하지 않습니다.
- 원글 저장이 실패하면 해당 답글은 저장하지 않고 오류를 표시합니다.
- D1 마이그레이션 없음.

주의: 기존 DB에 날짜가 임시로 기록된 동일 본문이 여러 건이면 수동 확인이 필요합니다.
