# PIA v0.3.6 — 임시 날짜 / 날짜수정필요

날짜 미상 CSV 행은 업로드 시점의 한국 날짜 정오(12:00)를 **임시 날짜**로 채웁니다. 공개 타임라인과 관리자 목록에 `날짜수정필요` 배지가 나타납니다. CSV 미리보기에서 날짜를 수정하면 배지가 해제됩니다. 관리자에서 게시물을 수정하면서 체크를 해제할 수도 있습니다.

## 필수 배포 순서
1. Cloudflare D1 원격 DB에 `migration-v0.3.6.sql`을 **한 번만** 실행합니다. (이미 적용했다면 재실행 금지)
2. ZIP 안의 `public/`, `functions/` 파일을 GitHub의 같은 경로로 업로드합니다. `public/style.css`는 v0.3.5 기반입니다.
3. `README.md`, `HISTORY.md` 갱신 후 배포합니다.
4. CSV 작업실에서 날짜 미상 행을 확인하고 수동 선택 후 등록합니다.

**주의:** 오늘 날짜는 실제 게시일이 아닙니다. 정오도 임의값입니다. 날짜수정필요 표시가 붙은 게시물은 반드시 추후 확인하세요. 기존 등록 게시물은 자동으로 표시되지 않습니다. 기존 게시물 중 날짜가 잘못된 항목은 관리자에서 직접 체크해야 합니다.
