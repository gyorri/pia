# PIA v0.3.13 — 기존 게시물 인용 연결

기준: 사용자가 제공한 pia-main 전체 ZIP 위에 v0.3.12 통합 패치를 반영한 소스.

- 관리자 인용 게시물 작성·수정에서 기존 게시물을 검색해 인용 대상으로 연결할 수 있습니다.
- 연결된 인용 카드 클릭 시 PIA 내부 원본 게시물 상세 화면으로 이동합니다.
- 미연결 인용 카드는 기존 직접 입력 방식을 유지합니다.
- 기존 인용 내용과 날짜, 기존 답글 연결은 유지합니다.
- 원본 삭제 시 연결만 해제하고 인용 카드의 저장된 본문은 유지합니다.

## 적용 순서
1. D1 데이터베이스 백업을 먼저 수행합니다.
2. `migration-v0.3.13.sql`을 실제 운영 D1에 **한 번만** 실행합니다. 이미 실행했다면 재실행하지 마세요.
3. ZIP 내 파일을 GitHub 저장소 루트에 경로대로 덮어쓰고 커밋/배포합니다.
4. 관리자에서 인용 게시물을 생성·수정하고 공개 카드 클릭 동작을 확인합니다.

주의: 연결된 원본 게시물의 내용을 나중에 수정하면 인용 카드에 저장된 스냅샷은 자동 갱신되지 않습니다. 기존 CSV 일괄 등록 스키마는 변경하지 않았으며 CSV를 통해 인용 ID를 자동 연결하지 않습니다. 운영 환경 통합 테스트는 하지 않았습니다.
