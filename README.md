# PIA v0.2.7 모바일 탐색 + 홈 통합 패치

v0.2.5 및 v0.2.6 미배포 변경을 포함한 통합 패치입니다. **v0.2.5, v0.2.6은 별도로 배포하지 마세요.**

## 변경 사항
- 홈은 전체 계정의 일반 게시물/인용 게시물을 원본 작성 일시 기준 최신순 표시 (답글은 홈에서 제외).
- 날짜는 닉네임 옆에 간략하게 표시 (상대 시간, 월/일, 과거 연도).
- 모바일 하단 탐색 메뉴: 홈 / 검색 / 계정 / 관리자. 프로필에 들어가도 홈으로 복귀 가능.
- `/\#/accounts`에서 전체 등록 계정 목록 확인 및 각 계정 프로필 이동.
- 모바일 하단 메뉴의 검은 배경을 현재 테마 배경색으로 변경.

## 적용
`public/app.js`, `public/style.css`, `public/index.html`, `README.md`, `HISTORY.md`를 동일한 경로에 덮어쓰세요. D1 마이그레이션은 필요하지 않습니다. 기존 데이터 유지.

## 검증
`node --check public/app.js` 문법 검사 및 ZIP 구성 검사 수행. 실제 Cloudflare 배포 및 모바일 실기기 동작은 아직 확인되지 않았습니다.
