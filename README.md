# PIA v0.3.3 — X 스타일 정밀 보정

v0.3.2를 기준으로 만든 누적 공개 화면 패치입니다. `public/app.js`, `public/style.css`, `public/index.html`을 같은 경로에 덮어쓰세요. 관리자 파일·API·D1 변경 없음.

## 변경
- 홈/검색/계정 메뉴 활성 상태 강조
- 프로필/게시물 화면 뒤로가기 헤더
- 게시물 간격·아이콘·라이트 모드·모바일 보정
- 우측 계정 둘러보기 카드와 프로필 이미지
- 게시물 공유 아이콘을 실제 아카이브 링크 복사 버튼으로 연결

참고: 실제 X의 추천 알고리즘, 반응 수, 북마크 기능을 구현한 것은 아닙니다. 인용/답글/빠른 등록/중복 경고 기능은 v0.3.2에서 유지합니다. 공개 사이트의 실시간 브라우저 렌더링 검증은 수행하지 못했습니다.
