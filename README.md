# PIA v0.2.2 패치

기준: v0.2.0 전체 소스 + v0.2.1 관리자 패치. ZIP에 들어 있는 파일만 원래 경로로 덮어쓰세요.

## 주요 수정
- 관리자 화면 로그인 상태는 `/api/session`으로 확인합니다. 공개 `/api/data` 응답을 로그인으로 잘못 판단하던 문제 수정.
- 새 계정은 사진 없이 생성하고 공개 화면에는 기본 사람 아이콘을 표시합니다. 등록 계정의 수정 버튼에서만 프로필 사진 URL 변경란이 보입니다.
- 공개 타임라인의 안내 문구 제거.

## 배포
1. GitHub 저장소에 ZIP 내부 경로 그대로 파일 덮어쓰기(특히 `functions/api/[[path]].js`).
2. Cloudflare Pages 환경 변수 Secret `ADMIN_PASSWORD`와 D1 바인딩 `DB` 확인.
3. Git 커밋 후 Pages 배포 완료 확인. 기존 D1 스키마 변경 없음.
4. `/admin.html`에서 로그인 후 계정 저장 테스트.

주의: `ADMIN_PASSWORD`를 변경하면 기존 로그인 세션은 무효화됩니다. 비밀번호를 공개 채팅에 붙여넣지 마세요.
