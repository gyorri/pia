# PIA v0.3.26 — 공개 화면 X 모바일/PC 통합 디자인 정렬

## 작업 목표
사용자가 제공한 실제 X 모바일 스크린샷(게시물 상세 + 아래 답글 카드, 일반 카드의 6개 액션)을 기준으로 PIA 공개 UI의 레이아웃을 통일합니다. 기존의 v0.3.20~0.3.25 CSS 보정이 하나의 파일에 중복 누적된 문제를 해결하기 위해 `public/style.css`를 **단일 스타일 체계로 전면 정리**했습니다.

**이 패치는 실제 최신 운영 GitHub 저장소에서 다운로드한 전체 소스가 아니라 이 대화에서 전달한 v0.3.25 공개 화면 소스에 기반합니다.** 운영본에 추가 변경이 있다면 반드시 대조 후 적용하세요. 관리자 기능용 v0.3.23 패치 및 API/DB는 수정하지 않습니다.

## 이번 변경점

### 모바일 상세 화면
- 아바타(40px)와 작성자 이름/아이디 2줄, 본문 전폭, 전체 작성 시각/조회수, 반응 바 순서로 정보 위계 정렬
- 실제 X의 5개 액션: 답글 / 리포스트 / 좋아요 / 북마크 / 공유 (하단 조회수 아이콘 제외)
- 384px 기준 5개 아이콘 중심 간격을 사용자 제공 X 캡처와 비슷하게 보정 (측정 중심 x≈32/112/192/272/352px; 화면 외곽 여백에 따라 변동)
- 조회수는 9,999 이하 천 단위 구분해서 `2,367 조회수`, 10,000 이상은 `1만 조회수`처럼 표기
- 작성 시각은 한국 시간으로 `오전 11:19 · 2026년 7월 19일`, 목록 날짜는 `7월 19일` 형태로 표기
- 다음 답글 상단에 인위적으로 추가되던 `답글` 헤더 제거, 부모 글 바로 아래 연결
- 답글의 부모가 바로 위에 보이는 경우 중복되는 '@아이디 님에게 보내는 답글' 표시 숨김 (실제 관계 데이터는 보존)
- 상세와 목록의 공유 모양을 사용자 제공 스크린샷의 3점 연결 방식으로 통일

### 타임라인/답글/인용
- 일반 게시물과 답글은 6개 액션: 답글 / 리포스트 / 좋아요 / 조회수 / 북마크 / 공유
- 384px 모바일에서 6개 아이콘 중심 x≈66/133/199/266/330/359px
- 게시물 아바타/작성자/아이디/본문/하단 아이콘 기준선 정렬, 글자 수에 따른 줄바꿈과 간격 처리
- 인용 카드의 작성자 영역·본문 여백·모서리, 원본 게시물 클릭 이동 기능 유지
- 숫자가 없는 게시물은 값을 만들지 않음. 목록의 북마크 숫자는 X 스크린샷과 같게 비표시, 상세에서는 실제 `bookmark_count`가 제공되는 경우에만 표시
- 로그인 여부와 무관하게 말줄임표 메뉴는 표시하되, 기존 관리자 권한 검증은 유지

### 나머지 공개 화면
- PC 3열(좌 275px/중앙 최대 600px/우 최대 350px), 중간 너비 아이콘 전용 사이드바, 600px 이하 모바일 하단 내비게이션
- 홈 탭, 검색 페이지, 프로필 커버/아바타/탭, 계정 목록, 오른쪽 계정 추천 패널을 공통 색/간격 기준으로 통일
- 다크 테마 변수, 모바일 세이프 에어리어, 긴 본문/계정명과 좁은 화면 처리를 유지
- 타임라인 빠른 등록/수정 모달과 중복 안내 스타일을 새 CSS에서도 보존

## 변경 파일 (저장소 루트 기준)
- `public/style.css` — 공개 UI CSS 전체 통합 정리 (기존 누적 중복 규칙 제거)
- `public/app.js` — 리스트/상세 날짜 및 조회수 포맷, 반응 바/연결 스레드의 UI 렌더링 정리
- `public/index.html` — CSS/JS 정적 파일 버전 v46 갱신
- `README.md`, `HISTORY.md` — 사용 방법 및 변경 이력 (배포 Git 로그를 대체하지 않음)

## 변경하지 않은 것
- `public/admin.*`, `public/import.*`, D1 SQL, API 코드, 계정/게시물 DB
- 이전에 구축한 관리자 입력 개선, 기존 글 인용 링크, 날짜 붙여넣기, 삭제 글 검색 최신화, 빠른 등록의 API 동작
- 원본 텍스트/작성일/조회수/좋아요 수/북마크 수 등 게시물 데이터

## 검사
- `node --check public/app.js` 통과
- Chromium 샘플 데이터 렌더링: 모바일 320/360/384/400/430/600px, 태블릿 768/1024px, PC 1440px × 홈/상세/프로필/검색/계정 화면
- 각 테스트 너비에서 가로 오버플로 없음, 리스트 6개·상세 5개 아이콘 확인
- 샘플 데이터의 검색 필터, 게시물 이동, 인용 원본 이동, 프로필 답글 탭, 빠른 답글 모달 열기/닫기, 다크모드 기본 색 점검
- ZIP 내부 파일 CRC 검사 및 개별 SHA-256 무결성 확인

## 적용
1. 운영 GitHub의 `main` 최신본을 먼저 백업하고, 특히 `public/app.js`·`public/style.css`의 기존 수정사항을 확인합니다.
2. ZIP을 **저장소 루트 기준**으로 덮어씁니다. 압축 폴더명 접두사는 없습니다.
3. GitHub에 커밋하여 Pages를 배포합니다. 기존 v0.3.23 관리자 패치는 별도로 덮어쓸 필요가 없습니다.
4. PC 및 휴대폰에서 홈 → 상세 → 인용 → 답글 → 프로필 → 검색을 실제 게시물로 확인합니다.

## 한계
- 스크린샷의 위치·여백을 기준으로 유사하게 조정했지만 실제 X 웹 앱의 전체 소스/폰트/상태를 복제한 것은 아니며 픽셀 단위 100% 일치는 보장할 수 없습니다.
- X 전용 AI/추천/소셜 상호작용과 PIA 관리자 목적의 메뉴는 동작이 다릅니다.
- 좋아요·리포스트·조회수·북마크는 실제 API에 있는 값만 보이고, PIA DB/API에 없는 메트릭은 표시하지 않습니다.
- 운영 서버와 실제 사용자 게시물에 대한 E2E 검사는 실시하지 않았습니다. 로컬 Chromium 샘플 데이터 테스트입니다.
